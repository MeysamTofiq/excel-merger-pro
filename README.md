# ادغام‌کننده اکسل — Excel Merger Pro

## معرفی (فارسی)

برنامه دسکتاپ ویندوزی برای **ادغام چند فایل اکسل** — شیت‌های همه فایل‌ها را **زیر هم** در یک خروجی واحد قرار می‌دهد و استایل‌ها (رنگ سلول‌ها، سلول‌های ادغام‌شده و ابعاد ستون‌ها) را هم دقیقاً کپی می‌کند. برای جمع کردن گزارش‌های شعب/هفتگی/ماهانه که هرکدام فایل جدا دارند، ایده‌آل است.

### ویژگی‌ها

- 📎 انتخاب چند فایل اکسل با یک تمیزِ برنامه
- 📑 شیت‌های فایل‌ها را زیر هم ادغام می‌کند (نه کنار هم!)
- 🎨 حفظ کامل استایل: رنگ، فونت، سلول ادغام‌شده، عرض ستون
- 👀 پیش‌نمایش قبل از خروجی
- 🖥 تم تیره/روشن

### فناوری

Python · openpyxl · PyQt5

### اجرا

```bash
pip install PyQt5 openpyxl
python excel_merger_pro.py
```

> نسخه‌های دیگر: `ExcelMergerApp.py` (نسخه اول) — رابط و امکانات متفاوت.

# Excel Merger Pro — Stack Excel Sheets Together

## Overview (English)

A Windows desktop app to **merge multiple Excel files** — it stacks all sheets **on top of each other** into a single output, while faithfully copying styles (cell colors, merged cells, column widths). Perfect for consolidating weekly/monthly/branch reports that arrive as separate files.

### Features

- 📎 Pick multiple Excel files in one go
- 📑 Merges sheets **vertically** (not side by side!)
- 🎨 Preserves styling: colors, fonts, merged cells, column widths
- 👀 Preview before export
- 🖥 Dark/light theme

### Tech Stack

Python · openpyxl · PyQt5

### Run

```bash
pip install PyQt5 openpyxl
python excel_merger_pro.py
```
